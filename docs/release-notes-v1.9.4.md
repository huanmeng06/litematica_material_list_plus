## ✨ 新功能

| 功能 | 说明 |
| --- | --- |
| 跨维度材料列表 | 可以明确选择其他维度的投影材料快照，M+L 会优先打开用户显式选中的投影。 |
| 维度材料快照 | 按世界、按维度保存投影材料状态，离开维度或重启游戏后仍可恢复对应列表。 |
| 材料偏好入口配置 | 新增“在材料列表中显示材料偏好按钮”选项；关闭后入口保留在“加载原理图”页面。 |
| Minecraft 版本构建 | 提供 `1.20.1`、`1.20.4`、`1.20.6`、`1.21.1`、`1.21.10`、`1.21.11`、`26.1.2` 和 `26.2` 正式构建。 |

## 🛠 修复与体验优化

| 项目 | 说明 |
| --- | --- |
| 维度缓存恢复 | 修复从末地退出并重启后，主世界投影材料缓存因原生投影索引尚未追上而丢失的问题。 |
| 投影选择状态 | M+L 优先使用显式选中的材料列表；跨维度查看时不会改变当前维度实际可编辑的投影，工具操作仍只作用于当前维度投影。 |
| 冰块库存统计 | 修复水桶转换为冰块后的库存统计，冰块按背包实际数量计入可用材料，不再被需求数量截断。 |
| 低版本偏好入口 | 恢复低版本“替换为偏好”按钮，并补齐旧版配置项翻译。 |
| 26.x 启动兼容 | 修复 Minecraft `26.1.2` 和 `26.2` 无法启动的崩溃问题。 |
| 原生缓存语义 | 维度缓存只信任 Litematica 原生投影记录，保留显式删除缓存的语义，不再把普通维度切换误判为离线投影。 |

## 📦 安装

1. 下载 Assets 中与 Minecraft 版本完全对应的 JAR。
2. 删除 `mods` 文件夹中的旧版 LMLP，确保只保留一个 LMLP JAR。
3. 安装对应版本的 Fabric API、Litematica、MaLiLib 和 JEI。
4. `SHA256SUMS.txt` 可用于校验下载文件。
